# 基于 FPGA 的数字滤波系统

面向带噪正弦信号的 15 阶线性相位 FIR 滤波系统，支持低通 / 高通 / 带通三种模式，
片内生成测试信号与噪声，滤波结果由 LED 亮度指示。

| 项目 | 指标 |
|---|---|
| 器件 | GW1NZ-LV1QN48C6/I5 |
| 系统时钟 | 27 MHz 输入，二分频得到 13.5 MHz |
| 采样率 | 1.5 MSPS（9 拍一帧） |
| 滤波器 | 15 阶线性相位 FIR，单乘法器分时复用 |
| 模式 | 低通 / 高通 / 带通，运行时可切换 |

---

## 一、一套源码，三种用法

工程里同时包含三个顶层，**共用同一套约束与引脚**，使用时只需切换综合顶层（Set as Top Module），
不需要改动任何源码，三种配置的比特流互不冲突，可分别烧录。

| 配置 | 顶层模块 | 用途 | 资源（逻辑 / 寄存器） | 时序 |
|---|---|---|---|---|
| ① 演示 | `dds_top` | LED 亮度指示 + 按键操作 | 1046 / 1152、760 / 957 | Fmax 14.08 MHz，无违例 |
| ② 采集（纯正弦） | `dds_top_debug` | 分析仪抓取滤波输出 | 850 / 1152、780 / 957 | Fmax 13.59 MHz，无违例 |
| ③ 采集（带噪） | `dds_top_noise_gao` | 分析仪同时抓取滤波前/后波形 | 832 / 1152、458 / 957 | Fmax 13.51 MHz，无违例 |

- 配置 ①：器件上电即运行，两个按键完成全部操作，噪声通路不参与综合；
- 配置 ②：省去按键与显示，把资源留给分析仪，模式与频点由文件顶部常量指定，
  配合 `gao/ip_test.rao` 采集 `u_fir/data_out`；
- 配置 ③：正弦叠加伪随机噪声后送入滤波器，`gao/ip_noise.rao` 同时采集
  `fir_in` 与 `u_fir/data_out` 各 12 位，可直接对比滤波前后的波形与频谱。
  该配置使用 256 点正弦表代替 IP，以把资源留给分析仪的双路探针。

切换方式：右键对应的 `.v` 文件 → Set as Top Module，重新综合即可。

## 三、上板步骤

1. 新建工程，器件选 `GW1NZ-LV1QN48C6/I5`。
2. 把 `rtl/` 下全部 `.v` 加入工程（三个顶层可以共存，综合时只使用选定的顶层）。
3. 加入 `constr/pin_constraint.cst` 与 `constr/timing_constraints.sdc`。
4. 右键 `dds_top.v` → Set as Top Module。
5. 综合 → 布局布线 → 下载。

上电现象：蓝灯点亮（低通 + 100 kHz），红灯保持固定亮度作参考。

---

## 四、按键操作（演示版）

| 按键 | 操作 | 功能 |
|---|---|---|
| A | 短按 | 恢复上电默认状态：低通 + 100 kHz，并复位数据通路 |
| A | 长按 ≥ 1 s | 循环切换滤波模式：低通 → 高通 → 带通 |
| B | 短按 | 循环切换频点：100 kHz → 300 kHz → 600 kHz |
| B | 长按 ≥ 1 s | 噪声开关（仅在 `NOISE_EN = 1` 时有效） |

长按操作在按住满 1 秒时动作一次，继续按住不会重复触发。

**灯效对照（蓝灯亮度）**

| 模式 | 100 kHz | 300 kHz | 600 kHz |
|---|---|---|---|
| 低通 | 亮 | 半亮 | 灭 |
| 高通 | 灭 | 半亮 | 亮 |
| 带通 | 灭 | 亮 | 半亮 |

## 五、频率响应（理论值，单位 dB）

| 频率 | 低通 | 高通 | 带通 |
|---|---|---|---|
| 100 kHz | 0.0 | −55.7 | −33.2 |
| 300 kHz | −6.0 | −6.0 | −2.5 |
| 450 kHz | −32.1 | −0.2 | 0.0 |
| 600 kHz | −44.2 | −0.1 | −5.9 |

滤波器采用 Hamming 窗设计，采样率 1.5 MSPS，截止频率 300 kHz（带通 250~600 kHz）。

## 六、主要参数

| 参数 | 位置 | 说明 |
|---|---|---|
| 频率字 `INC_100K` 等 | `dds_top.v` | f_out = INC × 13.5 MHz / 2^25 |
| `NOISE_EN` | `dds_top.v` | 1 = 综合噪声叠加通路，0 = 纯正弦 |
| 滤波系数 `c_lp / c_hp / c_bp` | `fir_3mode.v` | Q9 定点，1.0 对应 512 |
| `FORCE_MODE` | `fir_3mode.v` | 3 = 跟随按键；0/1/2 = 固定模式 |
| `FORCE_MODE` / `FREQ_SEL` | `dds_top_debug.v` | 采集版的模式与频点 |
| 消抖时间 `CNT_MAX` | `key_debounce.v` | 默认 270000 拍，约 20 ms |
| 长按时间 `LONG_PRESS_CNT` | `key_ctrl.v` | 默认 13500000 拍，1 s |
| 噪声幅度 | `noise_gen.v` | ±128 |
| 亮度增益 `GAIN_SHIFT` | `led_amplitude_drv.v` | 默认左移 2 位 |

更换采样率或截止频率时，需要重新计算三组滤波器系数并同步修改频率字。

## 七、仿真

```bash
iverilog -o tb sim/tb_dds_top.v rtl/*.v
vvp tb
python sim/sim_fft.py
```

测试平台会自动检查上电状态、按键功能与复位行为，并输出 `fir_out.csv`
（两列：滤波前 `fir_in`、滤波后 `fir_out`，1.5 MSPS）。
`sim_fft.py` 读取该文件，计算信噪比并绘制时域与频谱对比图。

测试平台通过参数 `SIM_NOISE` 控制是否在仿真中启用噪声通路。

## 八、片上逻辑分析仪

1. 把顶层切换为 `dds_top_debug`；
2. 加入 `gao/ip_test.rao`；
3. 重新综合并下载，在 GAO 中点击运行即可观察 `u_fir/data_out` 的实时波形，
   采样时钟为 `clk_half`，深度 1024。
